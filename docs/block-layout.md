# Блочная раскладка структуры

Дата: 2026-10-28. Схема не меняется: блок — это обычный фрагмент
`structure/*.json`. Отдельный файл блока нужен, чтобы команда читалась как
команда, а связи между командами были явными и ревьюились отдельно.

## Правила

1. **Один блок — одна команда.** Файл `structure/teams/<блок>.json` держит узлы
   блока и его внутренние связи.
2. **Идентификаторы с префиксом блока**: `code.lead`, `design.designer`.
   Точка разрешена в `id`; префикс исключает коллизии при слиянии фрагментов.
3. **Внутренние связи — внутри блока**, межблочные — только в
   `structure/links.json`. Так видно, где команда, а где интеграция.
4. **Модели — один общий `structure/models.json`**, блоки ссылаются на алиасы.
   Два блока не должны объявлять один алиас по-разному.
5. **Оценщик не обязателен.** Иерархия — это `delegate`; `review` добавляет
   проверяющего. Нет `review` — нет оценщика, и это валидно.

## Пример

`examples/blocks/structure/`:

```
models.json          // work
teams/coord.json     // coord
teams/code.json      // code.lead -> code.dev (delegate)
teams/design.json    // design.lead -> design.designer (delegate)
links.json           // coord -> code.lead, coord -> design.lead (delegate)
                     // code.lead <-> design.lead (peer)
```

Итог: 5 узлов, 5 связей (4 delegate, 1 peer), 3 слоя, ни одного `review` —
иерархия без оценщика. Проверяется командой:

```bash
node --input-type=module -e "import { createGraphRuntime, readGraph } from './lib/api.js'; const r='./examples/blocks'; console.log(readGraph(createGraphRuntime({roots:[r]}), r).summary)"
```

## Чего избегаем

- складывать два графа с одинаковыми `id` — получится `duplicate-node`;
- держать межблочные связи внутри блоков — граница команды размывается;
- дублировать `models` в каждом блоке — `model-conflict` при расхождении.

## Связи из панели

Кнопка «Добавить связь» в карточке узла пишет ребро автоматически: если оба
конца в одном файле — в него, если в разных — в `structure/links.json`
(создаётся при необходимости). Удаление — «×» рядом со связью. Ошибка (цикл
`delegate`, дубль) откатывает запись.
