Обновления двух плагинов: structure и workflow — одна полоса, два блока рядом

Сегодня версии живут в двух несвязанных местах: строка «Версия · структура неизвестно · релиз не проверялся» с одной кнопкой «Проверить релиз» и отдельная карточка «Workflow · не установлен» с кнопкой «Проверить Workflow». Ни одна из них не умеет обновлять, не различает «идёт проверка», «ошибка с причиной» и «обновлено — перезапустите DSH», и не задаёт порядок, когда обновления есть у обоих. Здесь — одна полоса «Обновления» под шапкой панели: два блока рядом, одинаковые состояния, честные кнопки.

Заказчик «Сделай макет двух блоков обновления рядом: structure и workflow. Где живут, как не конфликтуют с вкладкой валидатора и верхней панелью A; состояния; кнопки; геометрия; поведение на узкой панели; порядок при двух доступных обновлениях».

Правки для воркера — по пунктам
  1. Одна полоса. Заменить строку «Версия…» и карточку Workflow одним компонентом renderUpdatesBar() под шапкой панели; высота фиксирована 38.
  2. Данные. GET /api/updates → { blocks: [{ id:'structure', name, installed, available, state, reason, checkedAt }, …] }; состояние — state:'ok'|'new'|'checking'|'error'|'updated'.
  3. Порядок. Блоки рендерятся в фиксированном порядке ['structure','workflow'], а не в порядке ответа.
  4. Кнопки. «Обновить» активна только при available && state==='new'; у disabled всегда есть title с причиной (см. §04–07).
  5. Проверка. POST /api/updates/check с таймаутом 15 с; во время проверки состояние checking на этом блоке, сосед не блокируется.
  6. Обновление. POST /api/updates/apply по одному блоку; «Обновить всё» — последовательность, structure первой, один итоговый «перезапустите DSH».
  7. Хранение. structure/updates.json (вне graph.json): чтобы состояние переживало закрытие панели.
  8. Узкая панель. Медиа-правила: ≥ 1100 — полный блок; 1000–1100 — без кнопок; < 1000 — один чип со счётом; высота полосы всегда 38.
  9. Слой. z-index полосы ниже меню (46) и модальных окон (60); поповер z 40; канву не перекрывать.
  10. Тесты. [data-updates-bar], [data-update-block="structure|workflow"], [data-update-state]; проверки на порядок блоков и на title у каждой disabled-кнопки.
