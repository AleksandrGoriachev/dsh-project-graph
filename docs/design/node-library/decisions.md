# Библиотека узлов: решения заказчика (2026-10-31)

Основа — вариант `palette` (палитра слева). Ниже — что меняется по ответам заказчика.

## 1. Обмен только через сообщения

Прямого обмена между агентами нет: они общаются сообщениями, а папка общего обмена —
место, где эти сообщения лежат. Поэтому:

- нового вида связи `exchange` **не вводим**;
- узел «Папка общего обмена» **не соединяется с агентами** — его связь с миром —
  сами сообщения (портал обмена на схеме);
- на карточке узла пометка «только сообщения», а не `peer`.

## 2. Редактор разворачивается из самого узла

Вместо панели внизу — редактор, который раскрывается от карточки узла (поповер у
самого элемента графа): выбран узел — рядом с ним поля и связи; закрыл — схема
остаётся как была.

## 3. Нумерация новых узлов

Новый узел получает id `<тип>-<номер>`, начиная с 1: `critic-1`, `critic-2`,
`worker-1`, `exchange-1`. Существующий узел id не меняет.

## 4. Палитра сворачивается

Библиотека — колонка слева со сворачиванием/разворачиванием; в свёрнутом виде
остаётся узкая полоса с иконками и подсказкой, схема получает больше места.
