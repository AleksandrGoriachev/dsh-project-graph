# dsh-project-graph — история версий

## 1.0.78 — 2026-11-12

### Обмен между воркспейсами

- доставка без падения прохода: TDZ `answerRef` (0222);
- метки сторон и резолв адресата: `labels` из папки + `participants` профиля/рантайма (0225, 0226);
- `wakeDecision` будит `answer` на `answer`, а не только вопрос (0227);
- `wake` перебирает формы сообщения `text/parts/content` (0214);
- журнал: `skip:self`, `skip:no-plan` с `labelsSize`/`resolved` (0221, 0224);
- slow-скан доставляет при `exchangeWatch:false` (0212).

### Адресация папок

- `folders[].uid` — UUID v4, не отображается на графе, используется для адресации; `graph.js` валидирует
  uid (дубликаты — ошибка), отсутствие допустимо;
- `buildGraphDocument` сохраняет `folders` (раньше пересборка теряла папки);
- `exchange.js` пишет `Box: <uid>`; `exchange-watch` читает `box`;
- миграция `tools/folders-uid.mjs` идемпотентна (`changed=0` при повторе).

### Доставка в сессию адресата

- сессия адресата из переписки (`From` + `Session`) приоритетнее свежих сессий (0231);
- сессии субагентов исключаются по `launches.jsonl` (`childId`), `session-unknown` не становится
  адресатом (0232, 0233) — письма больше не уходят в judge-сессии (`owned by subagent routing`).

### Совместимость

- графы без `uid` продолжают работать; миграция — `tools/folders-uid.mjs`;
- для обмена нужны `participants` в конфиге и общий ящик.

### Известные долги (не блокируют)

- 10 критериев старых задач обмена сняты allowlist как подтверждённый долг (`docs/tasks/0207/regress.allowlist.json`);
- 0231/0232 закрыты решением заказчика «код в main», без judge-приёмки;
- 0011 в архиве (подпись невозможна, ключ отозван).
