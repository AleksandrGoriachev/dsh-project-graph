# Решения заказчика по макетам 2026-11-08

## 1. Вызов окна из узла/папки — вариант C

Дословно: «Вызов окна из узла/папки - берем C. Правый клик при наличии шестеренки не имеет смысла».

- Шестерёнка **всегда видна** в строке роли узла (не только по наведению); клик открывает окно узла.
- У папки — шестерёнка в шапке и бейдж участников; свойства папок внизу панели отсутствуют.
- **Правый клик по узлу меню не открывает.** Удаление — из окна узла («Настройки»), с подтверждением.
- Счётчик элементов: только в развёрнутой палитре (решение 2026-11-07), в свёрнутом корешке его нет.

## 2. Верх панели — вариант A с подсказкой

Дословно: «Верх панели — A, но с оговоркой, при наведении указателя мыши выводится подсказка текущего состояния плагинов, а нажатие уже открывает панель, которая на макете».

- Шапка — одна строка: название + чип статуса словом.
- **Наведение** на чип: подсказка «текущее состояние плагинов» (структура/плагин/движок и вердикт) без клика.
- **Нажатие** на чип: поповер с версиями и единственной кнопкой обновления (как на макете A).
- Клик по фону/повторный клик закрывает поповер.
