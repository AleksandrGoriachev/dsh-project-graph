## Правила поведения

### 1. Контекстное меню (01)

- Открывается по правому клику **на карточке узла**; по пустой канве — не открывается.
- Два пункта: **«Сведения об узле»** (id, роль, модель, назначение, связи) и
  **«Редактировать узел»** (поля, расписание, связи).
- Положение — в точке курсора со сдвигом **+8 px по X и Y**.
- Края: у правого края меню раскрывается **влево** (правый край = курсор − 8 px),
  у нижнего — **вверх** (низ = курсор − 8 px), у верхнего — вниз. Отступ от края
  всегда 8 px, меню не выходит за границы поля и не обрезается.
- Безопасная зона кнопок окна DSH — 120×56 в правом верхнем углу: меню туда не
  заходит (тот же `clampPopover`: верх ≥ 56 px, правый край ≤ ширина − 120 px).
- Клавиатура: `Shift+F10` или клавиша «Меню» открывает его у карточки, ↑/↓ —
  переход по пунктам, Enter — выбор, Esc и клик мимо — закрыть без действия.
- Правый клик по карточке папки обмена даёт те же два пункта; «Редактировать
  узел» у папки открывает редактор папки (экран 04).
- Обычный левый клик по карточке не меняется: выделяет узел.

### 2. «Сведения об узле» (02)

- Модальное окно **600×480** по центру, не нижняя панель: подложка затемняет
  панель, окно ничего не обрезает.
- Поля только для чтения: **id, роль, модель, назначение, связи**.
- Внизу — **«Редактировать»** (переходит в окно 03, без стопки окон), в правом
  верхнем углу — **крестик**; подсказка «крестик или Esc — закрыть».
- Закрытие: крестик, Esc, клик вне окна — окно просто закрывается, диалога нет
  (здесь нечего сохранять).

### 3. «Редактировать узел» (03)

- Модальное окно **640×672** по центру. Поля: **id** (только чтение, с пояснением
  «другой id — другой узел»), **Роль**, **Модель** (список), **Назначение**,
  **Расписание** (время + «ежедневно · Europe/Moscow» + переключатель включения),
  **Связи** (список с удалением крестиком и строка добавления: вид связи,
  направление, узел, «Добавить связь»).
- Внизу: **«Сохранить»** — основная кнопка; рядом «Удалить узел» (со своим
  подтверждением, в макеты не входит).
- **Крестик в правом верхнем углу вместо «Отмена».**
- В шапке при непустых правках — метка **«изменено · не сохранено»**.
- Ошибки записи остаются в окне и говорят тремя частями: что, почему, что
  сделать; окно при ошибке не закрывается.
- «Сохранить» записывает и **закрывает без диалога**.

### 4. Редактор папки обмена (04)

- То же модальное окно **640×672**, тот же крестик, тот же диалог при правках.
- Поля: **id** (только чтение), **Ящик** (путь + корень: workspace/shared),
  **Участники (метки)** — метки с удалением и добавлением, **Контракт**,
  **Оркестратор**.
- **Поля «Ветки» нет** — удалено вместе с `folderEditor.threads`.
- Кнопки: «Сохранить» (у черновика — «Создать папку»), «Обновить контракт»,
  «Список фактов», «Удалить папку» (с подтверждением). «Отмены» нет.

### 5. Диалог подтверждения (05)

- Появляется поверх редактора, только если поля изменены.
- Текст: **«Изменения не сохранятся. Закрыть без сохранения?»**, ниже — какие
  именно поля не сохранены.
- Кнопки: **«Продолжить редактирование»** (по умолчанию в фокусе) и
  **«Закрыть без сохранения»** (красная рамка).
- Esc и клик вне диалога = «Продолжить редактирование»: случайно не терять правки.
- «Закрыть без сохранения» закрывает сразу, второго вопроса нет.

### 6. Правило крестика (06)

| Состояние | Крестик / Esc / клик вне окна | «Сохранить» |
| --- | --- | --- |
| Полей не касались | закрывает сразу, без диалога | записывает и закрывает |
| Поля изменены | диалог подтверждения (05) | записывает и закрывает, диалога нет |
| «Продолжить редактирование» | — | возврат в окно, правки на месте, фокус в первом изменённом поле |
| «Закрыть без сохранения» | правки отброшены, окно закрыто, выделение остаётся на узле | — |

- «Изменено» — сравнение значений с моментом открытия окна, а не факт нажатия
  клавиши: вернули прежнее значение — диалога не будет.
- Крестик всегда означает «закрыть без сохранения», а не «спрятать».

## Что не меняется

- id узла и папки не редактируется: другой id — другой узел.
- Ошибки по-прежнему из трёх частей: что случилось, почему, что сделать.
- «Обновить контракт» (Rev+1 в ящик), «Список фактов», «Удалить папку»,
  «Удалить узел» со своими подтверждениями — на месте.
- Участники обмена и метки папки, «без модели» у папки, «только сообщения» на
  карточке папки.
- Данные и API не меняются: меняется только форма окон и способ их открытия.

## Сценарий целиком

1. Правый клик по карточке `judge` → меню у курсора (01).
2. «Сведения об узле» → модальное окно с id, ролью, моделью, назначением и
   связями (02).
3. «Редактировать» → то же окно заменяется редактором с полями (03).
4. Меняем роль и назначение → в шапке «изменено · не сохранено».
5. Крестик → «Изменения не сохранятся. Закрыть без сохранения?» (05).
6. «Продолжить редактирование» → правим дальше; «Сохранить» → запись и
   закрытие; «Закрыть без сохранения» → правки отброшены (06).

## Требует подтверждения

1. Правый клик по карточке папки обмена: макет ведёт в редактор папки (04), а
   не в редактор узла.
2. Метки участников папки сохраняются кнопкой «Сохранить» вместе с остальными
   полями (как в текущем редакторе папки), отдельной кнопки «Сохранить
   участников» в окне папки нет.
