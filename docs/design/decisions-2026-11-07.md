# Решения заказчика по макетам 2026-11-07

## Палитра: счётчик элементов

Решение заказчика (2026-11-07, дословно): «Счётчик на узкой панели вообще не нужен, его достаточно, когда палитра развёрнута для просмотра списка узлов».

- Свёрнутая панель (корешок): счётчика «6 элементов» нет вообще — только иконки/плитки.
- Развёрнутая палитра (список узлов): счётчик есть, одной строкой, без переноса; сокращение «6 элем.» допустимо только при нехватке места, полная форма — в подсказке.
- В реализации проверить оба состояния: collapsed → счётчика нет; expanded → ровно одна строка.

Остальные пункты макетов (вход в окно, правый клик, вкладка открытия, верх панели) — решение ожидается.
